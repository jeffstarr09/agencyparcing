Google Sheets (optional)

You do not need this. Results are always saved as .csv files in this folder, which open in Excel, Numbers or Google Sheets. Set it up only if you want rows written to your shared Sheet automatically.

Show me how
  1. Go to console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable Google Sheets API.
  3. Credentials → Create Credentials → Service account → create a JSON key and download it.
  4. Rename it service_account.json and put it in this folder.
  5. Open your Sheet → Share → paste the client_email from that file → give it Editor → Send.
  6. Come back here and reload this page.
